# Done Criteria

A track is not done unless it includes:

- code or content for its owned write-set
- tests or verification for the changed contract
- one smallest working example
- explicit blockers or none stated

## Milestone gates

- Day 3: contract freeze gate
- Week 2: first functional convergence
- Week 3: E2E integration gate
- Week 4: release candidate gate

## Export gate minimum

- hard lock coverage passes
- style unity passes
- global negative coverage passes
- segment duration passes
- no empty segments
- Excel workbook exports successfully
